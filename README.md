# ReWear — Marketplace Preloved

Website demo marketplace pakaian preloved menggunakan HTML, CSS, dan JavaScript murni.

## Fitur
- Beranda dan katalog produk
- Pencarian produk dan filter kategori
- Keranjang dengan tambah/kurangi/hapus jumlah
- Pembuatan pesanan demo
- Menu Pesanan Saya
- Pelacakan status Dikemas, Dikirim, dan Selesai (simulasi)
- Form untuk menerbitkan produk
- Penyimpanan data di `localStorage`
- Desain responsif untuk desktop dan ponsel

## Menjalankan secara lokal
Buka `index.html` di browser. Tidak perlu instalasi atau build tools.

## Publikasi ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `rewear-marketplace`.
2. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses deployment selesai. URL website akan ditampilkan pada halaman Pages.

## Catatan penting
Ini adalah **prototype front-end**. Keranjang, produk yang dibuat, dan pesanan tersimpan hanya pada browser/perangkat yang sedang digunakan. Checkout tidak memproses pembayaran sungguhan, belum ada akun pengguna, database, upload gambar, sistem chat, atau integrasi kurir. Untuk marketplace produksi, tambahkan backend/database, autentikasi, validasi server, pembayaran, dan layanan pengiriman. Produk contoh dan status pengiriman bersifat demo.
